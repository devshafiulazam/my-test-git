Short Note of Git & Github



github.com ওয়েবসাইটে গিয়ে একটি ফ্রি অ্যাকাউন্ট 

ব্রাউজার থেকে git-scm.com/download/win ওয়েবসাইটে যান এবং Click here to download 

git --version


git config --global user.name "Your Name"

git config --global user.email "your_email@example.com" 

git config --list 


কম্পিউটারের Desktop বা Documents-এ  my-test-git নামে একটি নতুন সাধারণ ফোল্ডার তৈরি করুন। 
my-test-git.txt নামে একটি সাধারণ টেক্সট ফাইল তৈরি করে তাতে লিখুন: Version 1: Hello Git! এবং ফাইলটি সেভ করুন। 

my-test-gitফোল্ডারের ভেতরের ফাঁকা জায়গায় মাউসের Right Click করে Open Git Bash here ক্লিক করুন। ৪. Git Bash উইন্ডোতে নিচের কমান্ডটি লিখে Enter চাপুন:
Bash
git init 

git status 


যাচাই: লাল রঙের লেখায় my-test-git.txt দেখাবে। এর মানে হলো ফাইলটি ফোল্ডারে আছে, কিন্তু Git এখনো এর ভার্সন সেভ করেনি।
ফাইলটিকে বক্সে বা Staging Area-তে যোগ করা (git add):

Bash
git add my-test-git.txt


টিপস: ফোল্ডারের সব ফাইল একসাথে যোগ করতে চাইলে git add . লিখতে হয়
যাচাই: আবার git status লিখে Enter চাপলে দেখবেন notes.txt লেখাটি সবুজ (Green) রঙের হয়ে গেছে। অর্থাৎ এটি সেভ হওয়ার জন্য প্রস্তুত।


স্থায়ীভাবে ভার্সন সেভ করা (git commit):
Bash

git commit -m "Version 1: Added initial notes"

এখানে -m মানে হলো Message। ভবিষ্যতে যাতে আপনি বুঝতে পারেন এই ভার্সনে কী কাজ করেছিলেন, তার একটি ছোট নোট এখানে লিখে রাখতে হয়।
যাচাই: স্ক্রিনে 1 file changed, 1 insertion(+) লেখা আসবে। অভিনন্দন! আপনার ফাইলটির Version 1 আপনার কম্পিউটারে নিরাপদে সেভ হয়ে গেছে।

পার্ট ২: GitHub-এ খালি রিপোজিটরি (Repository) তৈরি করা

এবার আমাদের সেভ করা ভার্সনটি অনলাইনে (GitHub-এ) পাঠাতে হবে। তার জন্য GitHub-এ একটি জায়গা তৈরি করতে হবে:

১. ব্রাউজারে github.com ওপেন করে আপনার অ্যাকাউন্টে লগইন করুন।
২. ওপরে ডান কোণায় + চিহ্নে ক্লিক করে New repository সিলেক্ট করুন।
৩. Repository name-এর ঘরে লিখুন: my-first-project
৪. নিচে Public সিলেক্ট করা থাকবে (এটি সবাই দেখতে পাবে; গোপন রাখতে চাইলে Private দিতে পারেন)।
৫. নিচের আর কোনো অপশনে (যেমন Add a README file) টিক দেবেন না—একদম খালি রাখুন।
৬. সবুজ রঙের Create repository বাটনে ক্লিক করুন।

যাচাই: ক্লিক করার পর একটি পেজ আসবে যেখানে Quick setup লেখা এবং একটি লিংক (যেমন: [https://github.com/your-username/my-first-project.git](https://github.com/your-username/my-first-project.git)) দেখতে পাবেন।
