Settings -> Branches -> Add branch protection rule চালু করে main ব্রাঞ্চে সরাসরি পুশ বন্ধ রাখতে পারেন
টিম ওয়ার্কের ৩টি গোল্ডেন রুল
সরাসরি main-এ পুশ করবেন না: GitHub-এর Settings -> Branches -> Add branch protection rule চালু করে main ব্রাঞ্চে সরাসরি পুশ বন্ধ রাখতে পারেন।
ছোট ছোট PR তৈরি করুন: একসাথে হাজার লাইনের কোড না পাঠিয়ে ছোট ছোট ফিচার অনুযায়ী Pull Request পাঠান, এতে রিভিউ করা সহজ হয় এবং Merge Conflict কম হয়।
.gitignore ঠিক রাখুন: পিসির লোকাল এনভায়রনমেন্ট ফাইল (.env, __pycache__/, node_modules/ ইত্যাদি) কখনোই পুশ করবেন না।
